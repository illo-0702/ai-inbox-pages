후속 요청 입력

같은 업체의 이대리가 "22일까지"라고 말하면, AI Inbox는:

  • ✓ 같은 관계의 같은 업무를 찾습니다
  • ✓ 마감만 9/20 → 9/22로 제안합니다
  • ✓ 금액은 유지합니다
  • ✓ 변경 이력을 기록합니다

✓ 업무는 항상 하나: 같은 업체의 같은 업무가 여러 담당자로부터 전달되어도, 변경사항만 추적됩니다.
