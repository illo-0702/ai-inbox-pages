## 추가로 확인한 것

- 실제 모델 응답: 로컬 OmniRoute(auto 라우팅)로 앱의 프롬프트를 보내 받은 응답 4건이 스키마·정규화를 통과(`tests/ai/fixtures/omniroute-*.json`). 프롬프트 주입 문구가 섞인 입력도 무시하고 두 요청을 분리.
- 동시 저장 두 건, 레이트리밋 동시 초과 시도, 음수 금액·존재하지 않는 날짜 입력 거부.
- PDF 입력: 헤드리스 Chrome으로 만든 실제 한국어 PDF에서 문장 추출, 화면 업로드 후 입력창 채움 확인.

## 확인하지 못한 것

- 앱이 OmniRoute에 **직접** HTTP로 붙는 경로: 사용자 OmniRoute가 클라이언트 API 키를 요구하는데 앱용 키가 아직 없음. 같은 요청 형식은 모의 테스트로, 실제 모델 응답은 CLI 경유로 확인했다.
- Gemini·OpenRouter 실제 호출, 이미지 글자 인식 실제 호출(키 없음 — 모의 테스트만).
- Turso·Vercel 실제 배포(배포 권한 없음 — `docs/deploy.md`에 절차).
- 암호 걸린 PDF 실제 파일(모의 테스트만).
